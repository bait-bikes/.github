# Contributing

Thank you for helping protect bicycle mobility.

1. Open an issue that describes the problem, affected users, evidence, and the smallest useful change.
2. Keep implementation effects at system boundaries and model domain rules as typed, testable transformations.
3. Update JSON Schema or OpenAPI contracts before changing cross-repository behavior.
4. Include tests and explain security, privacy, accessibility, and operational consequences.
5. Do not include active-case information, precise live locations, personal data, credentials, or confidential agency material.

Use a feature branch and a pull request. Do not rebase shared branches or force-push.
