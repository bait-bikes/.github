# Security policy

Do not report a suspected vulnerability in a public issue, discussion, pull request, commit, or social channel.

Until a dedicated private reporting address is published, use GitHub's private vulnerability reporting feature on the affected repository. If that feature is unavailable, contact an organization owner through GitHub without disclosing exploit details publicly.

Include the affected repository and revision, impact, reproduction conditions, and a safe way to coordinate. Never include real owner location data, credentials, decrypted environment files, or active investigative information.
